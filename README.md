# CodeAlpha E-Commerce Store

## Project Description
This is a basic E-Commerce website developed using Django as part of the CodeAlpha Internship Program.

## Features
- Product Listing Page
- Product Details Page
- User Registration
- User Login
- Shopping Cart Page
- SQLite Database Integration

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite

## Products Available
- Laptop
- Smartphone
- Headphones
- Smart Watch
- Keyboard

## Installation

1. Clone the repository
2. Install Django

```bash
pip install django
```

3. Apply migrations

```bash
python manage.py migrate
```

4. Run the server

```bash
python manage.py runserver
```

5. Open in browser

```text
http://127.0.0.1:8000/
```
